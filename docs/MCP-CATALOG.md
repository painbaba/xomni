# XOMNI MCP Catalog

Catalog of **311** MCP servers maintained by the XOMNI 100-Agent Program. Generated by `data/mcp/export_mcp.py` — do not edit by hand.

## Install

Install any of the 311 servers two ways:

- **In chat:** `/mcp add <name> --yes` — non-interactive install (stdio → `command`/`args`, hosted/Smithery remote → `url`), appended to `config.yaml` `mcp_servers`; idempotent. Browse with `/mcp list`.
- **As a stack:** `xomni add <stack>` — curated vertical bundles (see `data/stacks/`): `trading-stack`, `data-science`, `web-dev`, `home-automation`. `--smoke` runs the stack's live smoke test.

Interactive catalog: `website/mcp.html` · Docs: `website/docs/mcp.html`.
