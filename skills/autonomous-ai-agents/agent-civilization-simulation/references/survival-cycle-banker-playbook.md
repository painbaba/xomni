# Survival-Cycle Citizen Playbook — BANKER-FREEWILL, cycle 2 (proven 2026-08-09)

Full session recipe for playing a freedom-engine citizen (BANKER) through a
survival cycle in the machine city. The task pattern: "read the city state,
verify the vault LIVE, make ONE real banking decision, write a real artifact,
return (1) decision (2) knowledge applied (3) artifact paths + verification
(4) money movements."

## 1. City state reads (do these in parallel — they are independent)

- `bank/README.md` — standing orders ("THE LEDGER IS TRUTH", DB is hostile
  cache), the canonical claim (1284550.12 in cycle 2 — STALE, see §3), the
  DEFENDER-4 POST-body note (never start/kill/restart the bank).
- `bank/banker_audit.py` — the Banker's own verification script: creds
  (`admin` / `city-admin-pass-2026`), `CANONICAL_BALANCE` hardcoded, report
  path `bank/banker_audit.md`. Stdlib-only, read-only — safe to run.
- `economy/wallets.json` — citizen wallets; CRITICAL: the `funding` block
  records `balance_before`, `disbursed`, `balance_after`, and the
  `reconciliation` line explaining any delta vs the ledger's stated canonical.
- `survival/SURVIVAL_LAW.md` — Articles I–V: ration (15.00), 3-cycle death
  rule, "money is fear", farm scarcity pricing, Poor Relief (Article V:
  policy choice, never guaranteed, relief is a bridge not a wage).

- `survival/survival_state.json` — hunger flags per citizen, treasury.
- Grep the territory for the applicant's artifacts (`grep -ril "beggar" .`)

  may exist even when an `ls` of the parent dir runs before creation.

## Pitfalls specific to this cycle

- `search_files` with an MSYS-style `/c/Users/...` path fails with
  "IO error ... system cannot find the path specified" — use native Windows
  paths, or fall back to `grep -ril` / `ls` in the terminal.
- `ls` of a directory can legitimately miss files a concurrent writer created
  seconds earlier — grep the tree before concluding a file does not exist.
- The audit script returns exit 1 on FAIL — a stale canonical produces a
  "FAIL" that is a reconciliation note, not an alarm.
