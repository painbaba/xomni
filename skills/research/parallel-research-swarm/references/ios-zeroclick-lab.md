## Standout NOVEL findings (filter=PASSED + executed=true)
1. **plist XInclude (agents 26/28/30)** — `xi:include href="file:///etc/passwd"` bypasses the plist-xxe DTD/entity filter completely (XInclude is a separate XML inclusion mechanism; no DOCTYPE needed). Works inside `<string>`, `<key>`, `<array>` contexts; `data:` URIs; `parse="xml"` for arbitrary file parse; `xi:fallback` processed; SSRF to same host. This is the campaign's strongest finding — the classic "DTD filter but XInclude left open" gap.
2. **CoreMedia (agents 1/2/4)** — nested box sizes NOT validated (stsd child size=0 and 0xFFFFFFFF reach sample-descriptor parser); co64 64-bit chunk-offset overflow passes; moov 64-bit header declared-size=8 vs actual 0 passes; negative chunk offsets (stco 0x80000000, co64 -1) accepted → OOB CMBlockBuffer access semantics; stbl cross-box contamination (trun/tfhd/tfdt/sidx/senc/saiz/saio/sbgp/sgpd placed under stbl); empty sample tables (count=0) still execute; nested moov->trak->...->moov recursion accepted; mdat inside moov accepted.
3. **WebKit (agents 11/13/15)** — NUL/NBSP (0xa0)/soft-hyphen (0xad) inside scheme bypass filter (java\x00script:, java\xa0script:); data:text/javascript allowed while data:text/html blocked; HTML/hex-entity encoded schemes (&#106;avascript:, &#102;ile:///etc/passwd, mixed entities) — 12+ variants; NOVEL family: SVG SMIL `<animate attributeName="href" values="javascript:...">` with entity/tab/CR/NL/NUL variants — SMIL animate href not covered by tag-name filters.
4. **PassKit (agents 46/47/49)** — NO scheme allowlist on webServiceURL/barcode.message: javascript:, file:, content://, intent:, android-app:, android:beam:// all accepted; CRLF in authToken (header injection potential); \u0000 NUL in serialNumber/authToken/webServiceURL accepted; formatVersion=-1 accepted; truncated JSON prefix executes; top-level array wrapper accepted; double-percent-encoded param; __proto__ key traversal (prototype-pollution probe accepted); schema type confusion (array for passTypeIdentifier).
5. **AudioToolbox (31/34)** — ALAC: magic + any 4 bytes executes with zero structure validation (8-byte activation threshold); CAF: file-length 0 bypasses size filter while per-chunk sizes up to 0xFFFFFFFFFFFFFFFF accepted (heap-overflow primitive); chained alac+caff parser primitives.
6. **IOKit (17/18)** — 0xff-saturated length AND count fields simultaneously pass the filter AND reach dedicated usb-len-overflow execution; wTotalLength oversized accepted.
7. **NSKeyedArchiver (21/24)** — 500-level deep nesting bypasses container layer; shared-key-set marker (nskeyed_sharedkeyset) executes.
8. **AWDL (41/45)** — all-zero payloads enter parser (minimal parser entry); zero-trailer triggers execution; TLV with nonzero declared length; huge-length-alone insufficient (negative control).

## PITFALL — lab runner cloning (hit in this campaign)
`lab_agent_ios.py` was generated by transforming `lab_agent_android.py` (sed/python replace of CLASSES, OUT, LAB const, prints). The mission-prompt TEXT also embeds the old port as a literal string ("http://127.0.0.1:8897") — the first run silently probed the WRONG lab (Android lab on 8897 instead of iOS lab on 8896). Only 1 agent completed before detection.
FIX: after any lab-runner clone, `grep -c "<old_port>" <new_runner>` and `sed -i 's/<old_host>:<old_port>/<new_host>:<new_port>/g'`; also update OUT dir + print labels. Verify with `grep -c` on both ports and check `MISSIONS[0]['prompt']` contains the new port.
