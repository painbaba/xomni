## 8 emulatable style archetypes (for automated HTML motion-graphics + TTS + ffmpeg pipelines)

1. **Armchair Documentary** (Fern) — 20–30 min, weekly; illustrated 2D scenes + maps + atmosphere; calm storyteller VO. Best overall template.
2. **Motion Infographic Factory** (Infographics Show) — 10–20 min, vector characters/charts, branded template, volume play (6,252 videos).
3. **Map Journalism** (Johnny Harris / Vox) — 10–20 min; animated maps (zoom/pan/draw), bold type, kinetic data-viz; energetic VO.
4. **Cinematic Business Docu-Drama** (MagnatesMedia) — 25–40 min; dark graphics, film-score mood, cliffhanger pacing, chaptered arc.
5. **Tech/Business Case Study** (ColdFusion) — 12–20 min; stock footage + subtle overlays + slow zooms; relaxed conversational VO; solo-sustainable.
6. **News Commentary Explainer** (Dhruv visual style) — 15–25 min; footage + maps + infographics + on-screen text callouts; assertive VO.
7. **Internet Mystery Long-Form** (Nexpo / Barely Sociable) — 30–60 min; screenshots + slow Ken-Burns + eerie ambient sound; calm ominous VO; low volume, extreme per-video value (Barely Sociable ≈2.6M avg views on 36 videos).
8. **Short Faceless Commentary** (SunnyV2) — 8–12 min; images/screenshots + text callouts; neutral reporter VO; highest throughput, lowest production load.

Not emulatable: Real Stories (licensed broadcast footage) and on-camera presenter segments (Dhruv/JH) — but their graphics layers are.

## 10 cross-channel engagement patterns

1. Curiosity-gap titles everywhere ("Exposing a $1,900,000,000 Pharma Company", "The Slow, Painful, Greedy Death Of Angry Birds") — verified across fetched catalogs.
2. Open-loop hooks before any branding.
3. Narrative arc over fact-dump (even list-format TIS wraps facts in character mini-stories).
4. One signature visual motif per channel = brand recognition.
5. One consistent narrator voice = brand (ColdFusion: "I create and narrate all the videos on here").
6. Music/sound design carries emotion (Artlist, custom composers, curated soundtracks).
7. Documented sources build trust (Fern Google-Docs sheets, Nexpo pastebin, JH journalism).
8. Runtime matched to depth: ~10 min commentary → 15–20 explainer → 25–50 min premium docs (medians 27–48 across doc archetypes).
9. Regular cadence (Fern "almost weekly"; TIS 6,252 videos).
10. Faceless-by-design scalability: format survives team changes, franchises (TIS → 7 series; Newpress → creator network).
