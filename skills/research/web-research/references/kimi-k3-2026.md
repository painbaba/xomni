## Architecture (KDA)
- **KDA = Kimi Delta Attention**, a hybrid *linear* attention (descends from Kimi Linear/DeltaNet chunkwise recurrent form). 93 layers (1 dense): **69 KDA + 24 Gated MLA**; each block = 3 KDA + 1 Gated MLA + Stable LatentMoE FFN.
- KDA: bounded log-decay (scaled sigmoid, g_min=−5) so all causal tiles run as dense Tensor-Core GEMMs; full-rank data-dependent output gate; FP32 attention output during training.
- **AttnRes** (Attention Residuals): each layer selectively retrieves from all preceding layers via softmax over depth (learned pseudo-queries w) — "attention across depth."
- **Stable LatentMoE**: 896 routed experts / 16 active per token / 2 shared (sparsity 56); latent dim 3584 (0.5× hidden), expert hidden 3072. Stability: Quantile Balancing (aux-loss-free), Per-Head Muon, SiTU-GLU, Gated MLA.
- **KV-cache/economics**: KDA = constant-size recurrent state (no per-token KV growth); KDA-aware unified prefix cache (state + MLA KV blocks, external CPU-DRAM pool); Mooncake disaggregated inference with **>90% cache-hit rate on coding workloads**; blog claim: prefill cache ⇒ "highly competitive token price despite its scale."
- Quantization: **MXFP4 weights / MXFP8 activations** via QAT from SFT onward. Speculative decoding: MTP layer fine-tuned into EAGLE-3-style draft (7-step unroll).
- Sources: https://github.com/MoonshotAI/Kimi-K3/blob/main/k3_tech_report.pdf · https://platform.kimi.ai/docs/guide/kimi-k3-quickstart

## Training (from tech report)
- Pre-train: 4 text domains (Web Text, Code, Math, Knowledge) + vision corpus (captions, interleaved, OCR, perception, video, visual coding incl. SVG/3D/Webpage/Game/CAD); K2-style rephrasing recipe. ~**2.5× scaling efficiency vs K2**; cosine LR (1% warmup) beat WSD in their scaling-law study; weight decay 0.1.
- **NoPE** (no positional embeddings — KDA decay encodes position): extrapolates to 1M with no RoPE tricks. Context curriculum: 8K→64K pre-train, 256K→1M cooldown. Native multimodal from step 0.
- Post-training: SFT → RL (3 domains × 3 effort levels = 9 experts) → MOPD distillation. Data: knowledge-graph-guided task synthesis, verifiable agentic problems, mock Gmail/Notion/Slack/Canvas assistant tasks, GPU-kernel tasks, Autonomous Execution Tasks, web-dev tasks.
