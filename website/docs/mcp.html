    MCP Catalog & Stacks

    Install any of 311 MCP servers: /mcp add <name> --yes in chat, or xomni add <stack> for one-command vertical stacks.

    The 311-server catalog

    XOMNI ships a curated marketplace of 311 MCP servers — searchable and filterable, with install commands, connect steps, stars, verified/source badges and a keyless/needs-key security hint per server. The same data drives the in-chat /mcp list command and lives in data/mcp/catalog.json (markdown mirror: docs/MCP-CATALOG.md).

    Install a single server

    In chat, ask the agent to add a server — the --yes flag makes it non-interactive:

    /mcp add coingecko-mcp --yes

    This resolves the catalog entry into a host config block (stdio servers → command/args, hosted/Smithery remotes → url), appends it to config.yaml under mcp_servers, and reports the launch line. Re-adding an existing server is a no-op (idempotent). Restart the host or run /reload-mcp to load the tools (they appear as mcp__<server>__<tool>).

    Install a whole stack

    Vertical stacks bundle a curated set of MCP servers + skills behind one command:

    xomni stacks                      # list available stacks
xomni add trading-stack           # install: appends 5 MCPs to config.yaml
xomni add trading-stack --dry-run # preview the plan, write nothing
xomni add web-dev --smoke         # install + run the stack's live smoke test
    StackSkillsMCP serversSmoke test (live)
    trading-stack4yfinance, TradingView, CoinGecko, AlphaVantage, PolymarketCoinGecko BTC price API → 200
    data-science6arXiv, DuckDuckGo, Fetch, chroma, timeCrossref API → 200
    web-dev6Playwright, Chrome DevTools, Cloudflare, Supabase, Neonnpm registry → 200
    home-automation4Home Assistant (ha-mcp), Windows, mobile, time, memoryPyPI ha-mcp → 200

    The write is a surgical textual insert into the existing mcp_servers: block — comments, ordering and every other config section are preserved byte-for-byte (including empty-inline mcp_servers: {} forms). Missing or read-only config fails loudly with the exact fix. Stack definitions live in data/stacks/*.json.

    Smoke tests

    Every stack carries a live smoke_test (public API call + expected status). xomni add <stack> --smoke installs and runs it. Verified live for trading-stack: CoinGecko /simple/price?ids=bitcoin returns HTTP_STATUS:200 with the current BTC/USD price; the PolymarketScan hosted remote answers (auth-gated edge) at https://polymarketscan--jordan-s648.run.tools.

    Verify an install

    Run hermes mcp list (or /mcp list) to confirm each server is registered, then make a read-only tool call. The catalog validation (/mcp validate <path>) checks command resolvability, duplicate names and required fields.
