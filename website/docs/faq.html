FAQ

Quick answers to the questions people ask most.

What is XOMNI?

XOMNI is a composed agent: the strengths of seven proven agents — Hermes, OpenCode, jcode, Codex, Aider, Goose, and OpenClaw — ported in as plugins and hosted on one core. It ships with 14 plugins and a pool of 25 verified free models. The philosophy is compose, don't merge: pick the strengths you want, skip the rest.

Are the 25 models really free?

Yes. The pool is populated from the opencode.ai/zen/go/v1 endpoint and every model is verified before it's used. There is no billing and no hidden tier. XOMNI re-verifies the pool on a schedule and drops anything that stops working.

Which plugins are enabled by default?

The core set: waitperk, perkline, provider-pool, title-statusline, omni-memory, and sandbox-gate. Everything else — repomap, gh-ops, omni-media, and friends — enables with one line in config.

Why "compose, don't merge"?

Merging agents means reconciling conflicting configs, overlapping tools, and different assumptions — a maintenance nightmare. Composition treats each agent's strengths as reusable parts that plug into one host. When an upstream agent improves, you pull its strength in as a plugin update instead of rebasing a fork.

How does sponsorship work?

While the agent works, a sponsor line runs in the statusline. Each work event generates impressions, and each impression has a price. Your earnings per work event are min(0.5 × P × share, 0.5 × P), where P is the price per impression and share is the sponsor's share of impressions. You always keep at least half of every impression. Full details on the Sponsorship page.

Can I use my own API keys?

Yes — that's the BYO Provider flow. Any OpenAI-compatible endpoint, hosted or local, joins the pool alongside the free models. Keys are stored via env: references or the OS keychain, never in plaintext config.

Can XOMNI run fully offline?

Mostly. Point the pool at local models (see local-models plugin) and use local-only routing. Sponsorship and model-pool verification need the network; everything else works offline.

Which platforms are supported?

Windows via run.cmd, macOS and Linux via run.sh. Both launchers are thin: clone, run, done.

What are the 170 skills?

XOMNI ships with a catalog of 170 skills across 42 domains — from security research and fuzzing to creative work, cloud platforms, and media pipelines. Browse and search the full list on the Skills page.

Does XOMNI cost anything?

The agent itself is free and open source. The 25 free models cost nothing. Sponsorship is opt-in — if you enable it, the sponsor line pays you. See the Sponsorship docs for the exact formula.

Where do I get help?

Open an issue on github.com/painbaba/xomni. For security concerns, read the Security page first and report privately.
