Install XOMNI

XOMNI is a single repository with two launchers: run.cmd for Windows and run.sh for POSIX systems. The only runtime requirement is a recent node.

Requirements

  • node ≥ 20 (any recent LTS works).
  • git for cloning the repository.
  • An internet connection on first run — XOMNI verifies its free-model pool on startup.

Windows (run.cmd)

From a terminal (cmd or PowerShell):

cmd.exe
C:\> git clone https://github.com/painbaba/xomni.git
C:\> cd xomni
C:\xomni> run.cmd

You can also double-click run.cmd in Explorer — the launcher opens a terminal, installs dependencies on first run, and starts XOMNI.

macOS / Linux (run.sh)

bash
$ git clone https://github.com/painbaba/xomni.git
$ cd xomni
$ chmod +x run.sh
$ ./run.sh

First run

On first launch XOMNI:

  1. Installs any missing dependencies.
  2. Verifies the 25 free models in the pool against opencode.ai/zen/go/v1.
  3. Enables the default plugin set (waitperk, perkline, provider-pool, title-statusline, and friends).
  4. Starts the agent with the statusline and sponsor line visible.

Updating

bash
$ git pull --ff-only
$ run.cmd   # or ./run.sh on POSIX

Your config, keys, and memory live outside the repo checkout, so updates never clobber them.
